# आपके PEM सर्टिफिकेट का उपयोग करके ऐप साइनिंग गाइड

## आवश्यक सॉफ्टवेयर
1. विंडोज SDK (Windows SDK) - https://developer.microsoft.com/en-us/windows/downloads/windows-sdk/
2. OpenSSL - https://slproweb.com/products/Win32OpenSSL.html (Light वर्जन पर्याप्त है)

## स्टेप 1: आवश्यक सॉफ्टवेयर इंस्टॉल करें
1. विंडोज SDK को डाउनलोड और इंस्टॉल करें
2. OpenSSL को डाउनलोड और इंस्टॉल करें
3. OpenSSL को अपने सिस्टम PATH में जोड़ें (यदि इंस्टॉलर द्वारा स्वचालित रूप से नहीं किया गया है)

## स्टेप 2: ऐप्लिकेशन बिल्ड करें
अपने ऐप को बिल्ड करने के लिए निम्न कमांड चलाएँ:
```
npm run build:win
```

## स्टेप 3: sign-app.bat स्क्रिप्ट का उपयोग करें
1. sign-app.bat फाइल में SIGNTOOL_PATH के पथ को अपडेट करें
   - आपके Windows SDK के इंस्टॉलेशन पथ के अनुसार (संस्करण संख्या अलग हो सकती है)
   - सामान्य पथ: C:\Program Files (x86)\Windows Kits\10\bin\10.0.XXXXX.0\x64\signtool.exe
   
2. APP_FILE पथ में अपने बिल्ड ऐप का सही नाम सेट करें
   - यदि आपका ऐप नाम या वर्जन अलग है, तो इसे अपडेट करें

3. कमांड प्रॉम्प्ट खोलें और sign-app.bat स्क्रिप्ट चलाएँ
   ```
   d:\whats-blaster\sign-app.bat
   ```

## स्क्रिप्ट कैसे काम करती है
1. OpenSSL का उपयोग आपके PEM सर्टिफिकेट फाइलों (cert.pem और key.pem) को PFX फॉर्मेट में कन्वर्ट करने के लिए किया जाता है
2. SignTool (Windows SDK) का उपयोग आपके ऐप की एग्जीक्यूटेबल फाइल को साइन करने के लिए किया जाता है
3. डिजिटल हस्ताक्षर वेरिफाई किया जाता है
4. अस्थायी PFX फाइल को हटा दिया जाता है

## त्रुटि समाधान
1. यदि "SignTool not found" एरर आता है:
   - Windows SDK को इंस्टॉल करें या SIGNTOOL_PATH को सही करें
   
2. यदि "Error converting PEM files to PFX" एरर आता है:
   - OpenSSL इंस्टॉल करें और सिस्टम PATH में जोड़ें
   
3. यदि "Error signing the application" एरर आता है:
   - सुनिश्चित करें कि dist फोल्डर में आपका ऐप मौजूद है
   - APP_FILE पथ चेक करें
